# Fix: Attendance PDF Images Display Correctly

## Summary

This change fixes an issue where some photos uploaded from mobile devices appeared rotated when included in generated attendance PDFs.

Users were seeing images displayed correctly during upload and preview, but the same images could appear sideways in the final PDF. With this update, images in the PDF will now match the orientation shown to the user throughout the upload process.

## Before

Portrait photos taken on mobile devices could appear rotated in the generated attendance PDF.

## After
